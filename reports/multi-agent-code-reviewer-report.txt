======================================================================
  Multi-Agent Code Review System
======================================================================

Author: Maharshi Soni
Category: multi-agent
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
Multi-agent system with specialized agents (Security, Performance, Style, Orchestrator) collaborating via message-passing architecture for comprehensive code reviews.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - pydantic
  - click
  - rich
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * Four specialized review agents
  * AST-based code analysis
  * Message-passing architecture
  * Priority-based finding aggregation
  * Rich terminal output
  * Configurable review profiles

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Python files to review

  Example:
    python -m src.cli review src/ --profile thorough

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Code review findings

  Example:
    CRITICAL: eval() usage at line 15 (SecurityAgent)
